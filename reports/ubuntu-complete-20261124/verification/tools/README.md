# Isolated report tools

These are fixed isolated-lab report tools, not maintained production commands or generic deployment/transaction executors. Fixed private inputs are withheld. Historical initial-review/not-executed headers retain source-stage context; actual receipts determine execution. Do not run against live services or public chains.

Exact source bytes are retained. Their historical initial-review headers do not override the actual execution receipts. Private inputs and transport wrappers are intentionally withheld. Read the report and evidence before considering any reproduction.
