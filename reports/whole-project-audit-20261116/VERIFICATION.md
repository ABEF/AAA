The new Python modules can be selected directly through `unittest`; select only
the two adapted profile methods if checking that changed expectation. Website
`tests/deployment-signing-profile.test.mjs` is standalone under Node. Do not run
an entire maintained suite solely to reproduce these scoped results when its
remaining sources have not changed. Source-specific JSON records preserve the
exact selection used here.

Fresh bundle schema4 requires its exact operator fixtures; schemas1/2/3 keep
historical admission/instructions. Before invoking Git-dependent publication
checks, use an independently authenticated matching full Git checkout and
byte-compare the verified bundled inputs. Never fabricate Git history or relax
the provenance check to obtain a pass. Bundle exports and local checks do not
grant operating, signing, deployment or release authority.
