## Reconcile findings individually

For every substantive finding, unresolved recommendation and qualification
boundary, record a stable ID, original report/section, intended invariant,
current evidence, duplicates/related items, status, severity, owner, next action
and existing Todo link. Use explicit statuses:

- Fixed in this pass.
- Resolved by earlier current-source work.
- Superseded by an approved architectural decision, with the replacement rule.
- Accepted bounded limitation, with operational consequence.
- Open verification/engineering work, specifying missing evidence.

documentation drift, gas feasibility and actual release qualification. A mock,
