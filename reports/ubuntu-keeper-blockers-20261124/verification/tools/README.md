# Executed helper source

These are byte-exact members of the recorded isolated-lab archives, provided for
source review. The evidence manifest maps each stage to its archive and inputs.
Original draft/not-executed headers retain their preparation-stage wording;
actual receipts establish which paths executed. Required private input copies,
transport, disposable signing material and runtime journals are withheld.

These files are not maintained operator commands or a generic deployment tool.
The `common` helper was supplied beside each stage's helpers in its actual lab;
this inspection layout is not a runnable production package.
