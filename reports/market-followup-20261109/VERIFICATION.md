# Evidence and verification boundaries

The campaign performs read-only primary-source research, public on-chain calls,
bounded market discovery, actual-quoter calls and independent arithmetic/source
review. It submits no transaction or oracle update and performs no deployment,
subscription, paid service selection, exchange action or provider contact.

## Integrity and limitations

The current feed manifest is [feeds/artifact-sha256.json](feeds/artifact-sha256.json).
The current route index is [routes/README.md](routes/README.md), and its complete
manifest is [routes/PACKAGE_MANIFEST_v2.json](routes/PACKAGE_MANIFEST_v2.json).
Earlier manifests and final-named snapshots are retained as intermediate
evidence. The v2 index explicitly supersedes them, including the strict70-versus71
fee classification; no original failed payload is deleted or relabeled.

RPC methods are bounded read-only calls. All monetary route reads use the common
canonical hash; explicit follow-up feed anchors remain separate. Actual header
availability did not imply historical-state availability. The saved official-RPC
pruning error, alternate-provider recovery, HTTP401/403s, ABI lookup failures,
initial transport failures and postspot gaps remain visible. Unavailable values
are never converted into zero prices or assumed no-liquidity proofs.

Pyth fee getters are observed, not a qualified data-access or operating budget.
API3 offer parameters and verified Merkle membership are not an active feed,
completed subscription or guaranteed payable amount. Exact Chainlink runtime
equality with explorer output does not upgrade partial verification into
independent recompilation or identify its signer organizations. On this Orbit
network, source-reported block.number can be ancestor-chain height; the matching
configuration event was mapped by digest/content to its RPC L2 block.

No production code changed, so unchanged Solidity/Python/browser suites,
compiler/size gates and static-analysis evidence were not rerun. Verification
instead checks actual payload hashes, exact source pins, integer deductions,
read-only selectors, documentation links and Todo generation. Four unrelated
dirty files remain byte-identical and excluded from publication. Sites, public
null configurations, signer, Anvil8902, journals and paused heartbeat are preserved.

Saved collectors are archival evidence, not installed operator services. To
repeat a campaign, copy/review them in a fresh external output directory, select
new explicit anchors and retain the old payloads. Do not execute them in place
over a historical report or assume their recorded local paths are live settings.

All source-scoped prior reports remain immutable. Actual feed/route admission,
provider funding/SLA, whole-operation execution, target gas, operational recovery,
OpenSea/VRF/authorities and independent audit remain release work.
