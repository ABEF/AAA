# Earlier30 focused-method deep review

This assessment reads all30 distinct methods claimed by the16November operator-input report. It distinguishes intended purpose, actual assertions and fixture boundaries. Historical passes remain bound to their original source; they are not relabelled as current EVM, deployment, gas, provider or security acceptance.

## Corrections

- Seven negative/moving-market methods previously changed global fixture responses during the initial estimate, before the exact call at that same canonical anchor. A new fixture hook moves the mutation after the initial exact call; explicit final-stage assertions prevent the same error recurring.
- The strict wrapper test now rejects a deliberately changed copied launcher, rather than proving only that the valid launcher imports.
- Legacy annotation compatibility now compares an independent complete record, rather than only two explanation fields.
- Shared-struct documentation now follows each operation's actual generated link and checks its own meaning, rather than accepting phrases anywhere in the page.

## Verification scope

Ten existing methods were strengthened; only those methods ran. First selected run:9passed and1failed because the new test oracle used raw residual-close wording for consolidation. That is an audit-test mistake, not a demonstrated production bug. Only that assertion was corrected and only that method reran successfully. Thus10distinct changed methods pass across11executions;20unchanged methods were inspected and not rerun. The initial failure is preserved. No compiler, EVM, live RPC, signer, service or chain runs were needed.

The24manual methods exercise real preparers/encoders/catalogue checks with injected RPC. They do not independently execute Solidity or qualify actual gas/fees. The6annotation methods verify documentation producers and coverage; nonempty notes alone cannot prove semantic correctness. No current obsolete method was found in these30. No production tool defect was reproduced by this review.
