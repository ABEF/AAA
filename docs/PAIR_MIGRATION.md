# Historical different-pair executor design

**Historical reference, not current operator instructions.** The typed pair executor is removed. Current atomic pool moves require the same native ETH/fixed-ZZZ pair. External custody-address exits and issuer-exchange executors are removed. Terminal collective exit returns actual old ETH/ZZZ to NFT owners; any later exchange or new deployment is separate.
